# RenoMate Studio

Sajt za RenoMate Studio – vaš prijatelj u renoviranju (projektovanje i dizajn, nadzor, izvođenje).

- `index.html` – ceo sajt (tabovi: Početna, O nama, Naši projekti, Kontakt)
- `img/` – logo i fotografije projekata

Sajt je statičan i ne zahteva build. Za objavljivanje preko GitHub Pages:
Settings → Pages → Branch: `main`, folder `/ (root)`.

Forma „Pošalji upit“ otvara unapred popunjen email ka `renomatestudio@email.com`
(adresa se menja u konstanti `INQUIRY_EMAIL` u `index.html`).
